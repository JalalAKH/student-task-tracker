# student-task-tracker
# Team member
1. Jalal Akhoun 
2. Saad Alqahtani
A student task tracker app for organizing assignments, deadlines, and courses. Users can track upcoming and overdue tasks, registration and login, mark tasks as completed, search and filter tasks, view progress, and edit or delete them. These will allow each user to manage their coursework through their own account and track their academic tasks. So, our goal is to create a useful system that helps students manage their coursework more effectively.
