# Development Process

## Methodology
Our team will use Scrum to manage the development of the Student Task Tracker. Scrum will help us organize the project into smaller tasks and track our progress throughout development.

## Sprint Length
Each sprint will last two weeks.

## Sprint 1 Goal
The goal of Sprint 1 is to build the basic features needed for a student to access the system and begin managing assignments.

## Sprint 1 User Stories
- As a student, I want to register and log in so I can access my own tasks.
- As a student, I want to add assignments with deadlines and courses so I can organize my coursework.
- As a student, I want to mark assignments as completed so I can track my progress.

## Workflow
We will use the GitHub Project board to track our work. Tasks will move through Backlog, In Progress, and Done as we work on them.

## Team Process
Team members will work on assigned tasks during the sprint and use GitHub to track changes and progress. At the end of the sprint, we will review the completed work and decide what should be included in the next sprint.
